# ResMode 0.1.0-alpha.1 — unsigned preview

First public source release under the MIT license. Windows x64 / .NET Framework 4.8. Bundled Geist fonts retain the SIL OFL 1.1 license.

Includes automatic game-session resolution switching and desktop restoration, a local game library, persistent monitoring exclusions, game launching, local Steam achievement counts, multi-monitor window restoration, cover-derived hover colors and locally embedded Geist Sans/Mono typography.

## Download and verification

Download `ResMode-0.1.0-alpha.1-win-x64-unsigned.zip`, extract the complete package, review SHA256SUMS.txt and run Instalar.cmd. The ZIP is generated by the GitHub Actions build linked to this release's source commit. Source code is available from this tag and the GitHub source archives.

**This is an unsigned prerelease. SignPath approval has not been obtained.** Smart App Control or another application-control policy can block it; the installer should stop before replacing an existing installed copy when its executable selftests cannot run. Do not disable security protections to install this preview.

Automated build/test results are recorded in the linked CI run. They cover deterministic geometry, preferences/exclusions, process/path helpers, font loading, cover colors and hover lifecycle. They do not prove sustained game performance, every monitor topology or every application's window restoration. Interactive validation of the newly prepared UI changes is pending on the development PC because application control blocks the new build there.
