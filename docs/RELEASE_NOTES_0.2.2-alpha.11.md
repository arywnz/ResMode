# ResMode 0.2.2-alpha.11

Quando o ResMode liga a resolução de jogo, o aviso agora diz qual resolução escolher dentro do jogo. Em "janela sem borda", o jogo desenha uma janela do tamanho escolhido nas opções de vídeo: se ela for menor que a resolução da tela, o jogo aparece como janela em vez de ocupar tudo. Escolhendo no jogo a mesma resolução que o ResMode aplicou, a tela fica cheia. A mesma dica foi para o texto "Como funciona" das Configurações.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
