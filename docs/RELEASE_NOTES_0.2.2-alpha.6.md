# ResMode 0.2.2-alpha.6

Depois de atualizar, o ResMode abre sozinho e mostra a janela. Antes ele reabria só na bandeja, o que parecia que o app tinha fechado.

O app agora procura versões novas a cada 15 minutos, e não mais a cada 12 horas. A consulta é condicional: quando nada foi publicado, o GitHub responde "sem mudanças" sem enviar a lista, então ela é leve e não conta no limite de requisições. Quando sai uma versão nova, o aviso aparece em até 15 minutos, no sino, na bandeja e nas Configurações.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
