# ResMode 0.2.2-alpha.8

Corrige a reaplicação repetida da resolução com o jogo aberto. Na alpha.7, o Red Dead desfazia a resolução logo depois de o ResMode ligá-la, e os dois ficavam brigando a cada poucos segundos.

Agora o ResMode só liga a resolução de jogo de novo quando a janela do jogo volta ao primeiro plano, ou seja, quando você retorna ao jogo depois de um Alt+Tab. Enquanto o jogo está em segundo plano, o app não mexe na tela. Se o jogo desfizer a resolução 3 vezes seguidas, o app para de tentar por alguns minutos.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
