# ResMode 0.2.2-alpha.14

O histórico agora registra, 15 segundos depois de ligar a resolução de jogo, como a janela do jogo está na tela: tamanho, posição, se está maximizada, a resolução e a taxa de atualização da tela e a escala da janela. Quando um jogo aparece como uma janela pequena no meio da tela em vez de ocupar tudo, essa linha mostra se o problema é o modo da tela, o tamanho da janela ou o monitor. Para ver, gere o log nas Configurações.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
