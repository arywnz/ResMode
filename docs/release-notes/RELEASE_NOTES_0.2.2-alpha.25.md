# ResMode 0.2.2-alpha.25

O histórico agora diz de onde veio a resolução de cada sessão: "escolhida só para este jogo", "padrão para todos os jogos" ou "teste de resolução". Assim, quando um jogo abrir numa resolução que você não esperava, a linha "Resolução de jogo ligada" mostra na hora se foi a escolha dele ou a geral que valeu.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
