# ResMode 0.2.2-alpha.22

O aplicativo é o mesmo da alpha.21. Esta versão arruma o repositório e o README.

O repositório ficou organizado: scripts em `scripts/`, documentos em `docs/` e notas de versão em `docs/release-notes/`. O pacote ZIP e o MSI continuam iguais por dentro.

O README ganhou um aviso no começo: o ResMode é feito para ser usado com upscaling FSR 4 ou DLSS. Se o jogo tem FSR 3, o driver da AMD consegue trocar por FSR 4; de FSR 2 para baixo a imagem fica farinhenta.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
