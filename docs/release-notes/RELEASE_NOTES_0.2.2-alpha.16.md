# ResMode 0.2.2-alpha.16

Corrige um erro que aparecia ao atualizar ou sair pelo menu da bandeja: o app fechava o menu enquanto o Windows ainda o estava fechando, o que registrava uma falha no histórico e podia mostrar uma janela de erro. Agora o menu é fechado antes, e esse caso específico não gera mais aviso.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
