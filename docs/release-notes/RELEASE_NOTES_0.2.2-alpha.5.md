# ResMode 0.2.2-alpha.5

A correção da barra de tarefas voltou a funcionar. O app contava como "janela do Explorer aberta" duas janelas invisíveis de apps suspensos do Windows e ficava esperando para sempre, então o botão "Corrigir agora" e a correção automática depois do jogo nunca rodavam. Essas janelas agora são ignoradas.

O botão "Corrigir agora" nas Configurações ganhou o mesmo contêiner dos outros botões, para parecer um botão. O texto do nome do jogo nos cards ficou mais suave: deixou de ser encaixado nos pixels da tela, o que deixava as letras serrilhadas.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
