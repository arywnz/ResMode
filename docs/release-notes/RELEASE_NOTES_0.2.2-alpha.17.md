# ResMode 0.2.2-alpha.17

**Resolução por jogo.** No painel de cada jogo, o botão "Resolução" abre uma lista ao lado, sem fechar o painel, para escolher a resolução daquele jogo: a padrão, "normal" (o jogo fica na resolução do Windows) ou qualquer uma das maiores que o driver oferece.

**Testar resolução.** Nas Configurações, o botão "Testar" liga a resolução escolhida por uns 6 segundos e volta sozinho, para ver se o monitor aceita antes de jogar.

**Indicador de modo jogo.** Enquanto a resolução de jogo está ligada, uma etiqueta verde no topo da janela mostra "Em jogo · resolução · Hz".

**Ordem da biblioteca.** O botão "Ordem" ao lado das abas ordena por nome, mais jogados ou jogados recentemente. Os cards mostram o tempo jogado na linha da plataforma.

**Aviso na primeira abertura.** Se o monitor ainda não oferece uma resolução maior, uma faixa no topo explica que é preciso ativar o DSR (NVIDIA) ou o VSR (AMD), com um botão para o passo a passo.

**Texto nítido.** O nome e a plataforma nos cards voltaram a ser desenhados com o mesmo renderizador nítido do resto do app, no lugar da suavização que deixava o texto borrado.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
