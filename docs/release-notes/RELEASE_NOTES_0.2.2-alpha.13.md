# ResMode 0.2.2-alpha.13

Ao deixar o mouse sobre o ResMode na barra de tarefas, agora aparece uma prévia da última tela que você usou, no lugar do quadrado cinza com o logo. Quando a janela está aberta, a prévia mostra a tela de agora; ao minimizar, o app guarda como ela estava e entrega essa imagem ao Windows.

Centralizar o 2º monitor durante o jogo foi testado em 20 resoluções do monitor principal, de 640×480 a 3325×1871, maiores e menores que 1080p. Em todas o segundo monitor ficou centralizado na vertical (com posição negativa quando o principal é menor, para os dois continuarem alinhados pelo meio) e voltou exatamente para a posição original depois.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
