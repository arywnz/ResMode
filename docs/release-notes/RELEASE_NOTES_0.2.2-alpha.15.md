# ResMode 0.2.2-alpha.15

O cartão de Configurações agora tem a altura do próprio conteúdo. Em tela cheia ou numa janela com espaço ele aparece inteiro, sem barra de rolagem. A barra só aparece quando a janela é pequena demais para mostrar tudo.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
