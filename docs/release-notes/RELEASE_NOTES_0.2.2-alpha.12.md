# ResMode 0.2.2-alpha.12

Com o jogo aberto, o monitor ao lado do principal agora fica centralizado na vertical em relação a ele. Antes, quando o monitor do jogo ficava maior (por exemplo 3325×1871), o segundo monitor ficava pendurado na borda de cima: o mouse só passava de um para o outro na parte alta e os dois deixavam de se alinhar como estão na mesa. Ao fechar o jogo, o monitor volta exatamente para a posição de antes, junto com a resolução normal, e as janelas dele (como o Parsec) são devolvidas ao lugar.

Só entram nisso monitores lado a lado com o principal, à esquerda ou à direita; monitores acima ou abaixo ficam como o Windows deixou. Dá para desligar em Configurações › Tela › "Centralizar o 2º monitor". Se o PC desligar com o jogo aberto, a posição original também é restaurada na próxima vez que o app abrir.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
