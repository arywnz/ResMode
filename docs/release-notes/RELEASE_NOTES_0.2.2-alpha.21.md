# ResMode 0.2.2-alpha.21

Corrige a janela voltando da barra de tarefas com a barra de cima e o botão de ordem como retângulos brancos. A prévia da barra de tarefas (alpha.13) só fica ativa enquanto a janela está minimizada, e não toda vez que o mouse passa pelo botão, e ao restaurar a janela o app manda redesenhar todos os controles.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
