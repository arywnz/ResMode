# ResMode 0.2.2-alpha.4

Janelas em outro monitor, como o Parsec, voltam para o lugar quando o jogo troca a resolução. Antes, quando o Windows reduzia a escala da janela durante a troca (o DPI dela mudava) e a jogava no monitor principal, o app desistia de devolvê-la. Agora ele devolve ao monitor e ao tamanho de antes.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
