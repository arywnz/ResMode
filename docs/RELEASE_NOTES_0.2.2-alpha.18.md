# ResMode 0.2.2-alpha.18

**Guia de boas-vindas.** Na primeira vez que a janela abre, um guia de quatro passos explica o que o ResMode faz, como conseguir uma resolução maior (com o estado do seu monitor), a biblioteca e a bandeja. Quem já tinha jogos na biblioteca não vê o guia depois de atualizar. Dá para rever em Configurações › Guia de boas-vindas › Rever guia.

**Biblioteca vazia.** O estado vazio ganhou o logo, um título e uma frase dizendo o que fazer, no lugar de uma linha solta. A busca sem resultado também ficou mais clara.

**Correção.** Os textos do painel de resolução por jogo (alpha.17) apareciam com acentos quebrados. Corrigido.

MSI para Windows x64, sem assinatura digital. Feche o ResMode antes de atualizar, quando nenhum jogo estiver aberto. As configurações são preservadas.
